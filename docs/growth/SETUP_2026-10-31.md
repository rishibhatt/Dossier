## 2. How billing works

- Every purchase is one Razorpay payment (UPI, cards, net banking). No mandates, nothing auto-renews.
- Starter ($9 / ₹399): owned for good. Pro: 30 days ($7 / ₹299) or 365 days ($39 / ₹1,499); buying more stacks on the days left. When Pro ends the account falls back to Starter (if bought) or Free.
- The server sets the amount (`PRODUCTS` / `priceFor` in `src/lib/billing/pricing.ts`) and checks it again before granting. Grants are idempotent (`grant_purchase`), so the checkout callback and the webhook can both arrive safely.
- Full refund or lost dispute takes back exactly what that payment bought (`revoke_purchase`). Partial refunds change nothing.
- Festival offers (`OFFERS` in the same file) cut the price server-side and show a countdown bar. Diwali (INR only) starts 1 Nov 2026; Black Friday, New Year and graduation season follow.

### Test it (test mode, no money moves)
1. Sign in → Dashboard → Plan & billing → "Get Starter".
2. In the Razorpay popup: Netbanking, any bank, Success (or `failure@razorpay` to test a failure), or card `4100 2800 0000 1007`, any future date, any CVV, OTP from the screen.
3. Expect: toast "Starter is on", plan shows Starter, receipt email, a row in `/admin` → Latest subscriptions.
4. Refund it in the Razorpay dashboard → within a minute the plan goes back to Free (webhook).
5. Razorpay → Webhooks → your hook shows each delivery and its response code. A 500 means it will retry.

## 3. Emails

**What sends now**
- Account: welcome, sign-in notice, password changed, receipt, plan change, referral credit, contact reply. Always sent.
- Product (on by default, one-click off): share kit right after the first publish; then daily at 10:00 IST: activation nudge (day 1–4, nothing built), resume → site (day 3–14), invite friends (7 days after publishing), weekly visits (Mondays, 3+ visits), one win-back (30 days away). At most one product email per person every 3 days, never to test accounts.
- Money: Pro ends in 5 days / Pro ended. Sent regardless of the product setting.
- Offers: off until the person ticks it in Settings. Nothing is sent from this list automatically yet.
- Every product email has a working unsubscribe link and the `List-Unsubscribe` one-click header (Gmail/Yahoo need it).

**Test that mail really comes from hello@dossier-cv.com**
1. Brevo → Senders, Domains → `dossier-cv.com` must show **Authenticated** (SPF, DKIM, DMARC records added at your DNS host). `hello@dossier-cv.com` must be a verified sender.
2. `/admin` → "Email me one copy of every app email". You get 10 messages marked `[TEST]`.
3. In Gmail open one → ⋮ → **Show original**. Want: `SPF: PASS`, `DKIM: PASS` with `d=dossier-cv.com`, `DMARC: PASS`, and From `hello@dossier-cv.com`.
4. Send one to the address from https://www.mail-tester.com and aim for 9/10 or more.
5. Replies: make sure the `hello@` mailbox exists and receives mail (send it a message from your Gmail). Brevo only sends; it does not host the inbox.
6. Run the daily job by hand: `curl -H "Authorization: Bearer $CRON_SECRET" https://dossier-cv.com/api/cron/emails` → `{"picked":N,"sent":N}`.

**WhatsApp:** email only for now, as you chose. Users can share their own site on WhatsApp from the dashboard ("Send on WhatsApp", a free wa.me link). For automated WhatsApp later, use a second number on the WhatsApp Cloud API (utility messages are about $0.0025 each in India); your personal number would leave the WhatsApp app if registered.

## 4. Visits, sharing, tools, LinkedIn

- Published sites count one visit per browser per day, only after a real tap, key or wheel, never bots, never the owner. Dashboard shows the 7-day count (all plans) and a 14-day bar chart plus 30-day total (Pro). Each site also has "Share on LinkedIn" and "Send on WhatsApp".
- Free tools now remember what you typed in that browser (except the resume text in the ATS checker, for privacy). The job-description match and the "use this in a resume" hand-offs were already there.
- LinkedIn: scraping a profile URL is against LinkedIn's terms and gets blocked, so Dossier takes the official export instead: profile → More → **Save to PDF** → upload. The upload screen says so. The offline reader now understands that layout (sidebar first, "Top Skills", 3-part locations, "(2 years 8 months)"); tested with a sample export and a classic resume.

## 7. Custom domains (Pro, after billing proves itself)

Free options, no new vendor bill:
- **Netlify domain aliases** (simplest): the owner points a CNAME (`www.theirname.com` → `dossier-cv.netlify.app`); Dossier adds it to the site's domain aliases through the Netlify API and Netlify issues the HTTPS certificate. `src/proxy.ts` maps the host to that person's published site. Netlify caps aliases per site, so fine for the first ~100 Pro users.
- **Cloudflare for SaaS**: 100 custom hostnames free, then $0.10 each a month. Needs `dossier-cv.com` DNS on Cloudflare. The path once you outgrow Netlify aliases.
Neither is built yet; the pricing page still marks it "planned".
